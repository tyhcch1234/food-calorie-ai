    搜尋食物

      Vision API 設定

      不填也可用：預設的離線模型在你的瀏覽器內完成辨識。填 API Key 可獲得更準確的多食物辨識與份量估算，相片屆時會傳送到你指定的服務商。

      Key 只儲存在你這部裝置的 localStorage，不會上傳到本網站（本網站沒有後端）。可用 OpenAI、Azure OpenAI 相容網關，或 Gemini 的 OpenAI 相容端點（https://generativelanguage.googleapis.com/v1beta/openai）。

      怎麼用

      1. 上載相片：拖放、選擇檔案、拍照或直接貼上。
      2. 確認食物：頂部幾個候選是模型判斷，按一下即加入；不確定就按「手動搜尋食物」自己揀。
      3. 調整份量：拉動滑桿或用碗／隻／片等常用份量，卡路里與營養素即時更新。
      4. 看總數：右邊會累計這餐的熱量、三大營養素比例、纖維、糖與鈉，並對照每日目標。

      離線模型第一次使用需下載約 150MB 權重（之後會快取），需網絡連線；API 模式則每次辨識都會發送相片到你的 API 服務商。
